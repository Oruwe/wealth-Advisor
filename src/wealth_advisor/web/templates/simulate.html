What happens in a run

1. IPS reader
Lyzr agent reads the client's Investment Policy Statement and extracts verified facts.
2. Risk engine
cvxpy optimizer computes target weights using mean-variance optimization with suitability caps.
3. Tax engine
HIFO lot selection minimises realised gains; wash-sale flags protect the loss.
4. Suitability gate
Re-derives the post-trade portfolio from orders and verifies every FINRA suitability rule.
5. Briefing writer
Lyzr agent explains each number — checked against facts before acceptance.
6. Ledger
Every figure is hashed into a tamper-evident chain entry. You approve or decline.
